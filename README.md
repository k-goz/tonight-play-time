# 今晚还能玩多久

亲子作业时间管理 PWA。它把“催孩子写作业”转化为一条由孩子自己掌握的正向反馈闭环：越早认真完成，睡前可自由安排的时间越清晰。

## 当前能力

- 北京时间与每个孩子独立的工作日 / 周末睡觉规则
- 作业开始、暂停、继续、完成计时
- 家长三项确认：作业、订正、态度
- 完成庆祝、快乐时间项目选择
- 7 天 / 30 天记录与本周星星图
- 无账号本地模式：数据保存在 `localStorage`
- 家庭账号自动生成默认孩子档案，最多同时使用 6 个孩子档案
- 顶部快速切换孩子；每个孩子拥有独立记录、两套睡觉规则和本地缓存
- 家长数据页可新增孩子、修改昵称、调整当前孩子规则，并安全归档 / 恢复非默认档案
- 孩子完成作业时必须经过一次家长 PIN 确认；该确认不能用于进入管理页面
- 家长模式由服务端签发 15 分钟短时授权，支持主动锁定和刷新恢复
- 账号模式：家庭档案、记录、睡觉时间和家长设置同步到 Node.js + SQLite 服务端
- 首次进入家长模式时迁移旧本地记录；重复执行不会产生重复数据
- 旧单孩子数据库记录会自动归入默认孩子档案；旧睡觉时间同时继承为工作日和周末规则
- 账号数据按“账号 + 孩子”隔离缓存，切换账号或孩子不会串用记录
- PWA 安装与静态资源离线缓存
- 家庭启动台、本设备默认孩子和家长控制的孩子切换权限
- 每个孩子独立的当日 / 暂停过久 / 临睡提醒；通知受阻时自动降级为应用内提示并记录触达状态
- 周目标、连续完成、中断保护、家庭奖励确认和成长周报
- 会话版本控制、离线更新队列、服务端冲突留档和家长版本裁决
- JSON 导出与恢复导入；SQLite 在线一致性备份、显式恢复与完整性验证脚本
- 登录 / PIN 限流、敏感操作审计、数据库健康和运行状态面板
- 家庭版 14 天无扣款体验、价格意向与激活 / 7 日留存 / 周使用指标

## 使用流程

```text
登录或本地模式
  → 开始作业
  → 计时中（可暂停 / 继续）
  → 我写完啦
  → 家长检查确认
  → 庆祝与快乐时间选择
```

应用状态机：`idle → running ⇄ paused → reviewing → completed`。

## 技术结构

```text
index.html / style.css       页面与样式
app.js                       状态机、计时、渲染、本地持久化与同步触发
time-utils.js                北京时间、睡觉时间与时长计算
api-service.js               认证、会话、设置与迁移 API
service-worker.js            PWA 静态资源缓存（API 不缓存）
backend/server.js            Express API、认证、SQLite、静态文件白名单
scripts/                     SQLite 备份、恢复和生产完整性检查
backend/data/                本地数据库目录（不进入 Git）
tests/                       API、安全边界与时间计算回归测试
```

项目只保留 Node.js 后端。最低要求 Node.js 20.17。

## 本地运行

```bash
npm install
npm start
```

默认访问：<http://localhost:8001>

如需指定端口或数据库：

```bash
PORT=8080 DATABASE_PATH=/absolute/path/tonight_play_time.db npm start
```

不要直接双击 `index.html`：账号 API 和完整 PWA 能力需要通过 Node 服务访问。

## 数据与安全说明

- 密码使用带随机盐的 `scrypt` 保存；旧版 SHA-256 密码在成功登录后自动升级。
- 家长 PIN 在账号模式下同样使用带随机盐的 `scrypt` 保存，只能通过服务端验证，不会下载明文。
- 登录 Token 的摘要保存在 SQLite，服务重启不会强制退出。
- 会话更新采用字段白名单。
- 新增孩子、修改档案、归档、规则设置、历史导入、统计与批量清空都需要服务端家长授权。
- 作业完成使用 5 分钟内有效且只能消费一次的确认令牌；已完成记录不能由孩子改写或删除。
- 会话唯一键为“账号 + 孩子 + 日期”，孩子档案访问始终校验所属账号。
- 归档只让档案退出日常切换与读写入口，不删除档案或历史会话；默认档案不能归档。
- 旧本地记录迁移规则：云端无记录则导入；云端未完成则由本地完成记录补齐；云端已完成则保持云端版本。
- 数据库升级到 V5 时会保留历史记录并新增提醒、成长、冲突、审计和产品验证结构；升级前仍应备份 SQLite。
- 数据库位于 Web 静态目录之外。
- 部署只使用 SSH Key，不在仓库中保存密码。
- 家长 PIN 是家长数据页的轻量隔离层，不替代账号密码、HTTPS 或设备访问控制。
